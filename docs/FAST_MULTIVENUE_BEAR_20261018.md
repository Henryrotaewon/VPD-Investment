# FAST 거래소 복원 및 하락장 파생 확장 — 2026-10-18

사용자 요청: 기존 업비트·빗썸·바이낸스·크라켄 FAST 범위를 복원하되 빗썸부터 연결하고,
해외 파생을 활용한 하락장 PAPER 전략을 확장한다. 실제 주문은 실행하지 않는다.

## 현물 FAST

- 기존 업비트 프로세스·원장을 유지하며 빗썸 KRW, 바이낸스 현물 USDT,
  크라켄 현물 USD의 독립 감독 프로세스를 추가한다.
- 각 신규 원장 경로는 `fast-observe/venues/<venue>/observe.sqlite3` 및
  `paper-v1.sqlite3`이다. 동일 자산도 거래소 간 시세·신호·현금을 합산하지 않는다.
- 각 추가 계좌는 가상 300만원을 공개 환율의 매도호가로 현지 통화에 선배치한다.
  현재 원화 평가는 공개 매수호가 환율을 사용하고 오래된 환율은 갱신 대기로 표시한다.
  USD 환산에는 업비트 USDT/KRW와 크라켄 USDT/USD를 함께 사용한다.
- 같은 10초 수급 확인, 과거 10일 동일 5분 거래대금, 1.5% 추격 상한, 새 호가 모의체결,
  보호선·수급 청산을 사용한다. 신규 원장의 최소 주문 예산은 KRW 5천원/외화 5단위다.
- 빗썸 KRW-Q를 첫 구독·과거자료 복구 대상으로 둔다. 종목 목록은 제한하지 않는다.
  신규 종목 목록을 30초마다 재확인하며 목록 실패 시 기존 연결을 유지한다.
- 빗썸은 Public WebSocket v1, 바이낸스는 raw trade와 partial depth5,
  크라켄은 v2 instrument/trade/book10을 사용한다. 크라켄 호가는 Decimal 기반
  checksum을 확인하며 불일치 시 해당 연결의 관측을 초기화한다.
- 바이낸스 partial depth는 거래소 시각이 없어 수신 시각·단조 증가 순서번호로 검증한다.
  이 제약을 상태에 표시하고 원체결은 실제 거래소 시각으로 신선도를 확인한다.
- 크라켄 REST는 최근 720개 5분봉으로 제한된다. 원래 10일 조건을 줄이지 않으며
  부족한 일자의 자료는 축적 대기로 남긴다. 과거 급등·주문은 소급 생성하지 않는다.
- 추가 거래소 과거 거래대금은 하루 288개 정확한 double을 압축 저장한다.
  NaN=미확인, 0=검증된 무거래를 구분한다. 최근 상세봉 24시간, 비교자료 10일,
  최소 진단 24시간을 보존하며 64MiB 저장공간 여유 기준을 그대로 따른다.
- 모의 수수료 가정: 빗썸 0.25%, 바이낸스 현물 0.10%, 크라켄 현물 0.40%,
  슬리피지 각 편도 0.05%. 실제 계정 수수료·프로모션을 뜻하지 않는다.
- 텔레그램 FAST 전략세부와 FAST 메뉴의 `거래소별 운용`에서 범위·수신·준비 상태와
  별도 계좌 성과·보유·최근 체결을 확인한다. 기존 업비트 상세 화면의 범위를 명시한다.

## 해외 선형 무기한 하락장 후보

FAST-DERIVATIVES 기존 가상원금 총 300만원과 6개 지갑을 공유한다.
신규 가상 자본·차입·실제 주문을 추가하지 않는다. 종목은 기존 BTC/ETH/XRP/SOL/NEAR다.

| 모델 | 진입 가설 | 청산 |
|---|---|---|
| SHORT_BREAKDOWN | BTC 4시간 DOWN + 해당 선물 EMA20<EMA50·하락 + 직전 20봉 저점 종가 이탈 + 거래대금 1.5배 | 기술적 손절 0.4~1.5%, 목표 2R, 최대 2시간 |
| SHORT_RETEST | 같은 국면·선물 추세 + 과거 실제 저점 이탈 + EMA20 반등 후 음봉·직전 저가 이탈 | 같은 기술적 손절·2R·시간 제한 |
| 기존 SHORT/BASIS | 기존 업비트 기반 추세 숏 및 비용 차감 현선물 쌍 | 기존 포지션 청산 규칙 보존 |

새 모델은 바이낸스·크라켄 해당 선물의 완료 5분봉만 사용한다. 미래 봉·과거 pivot을
참조하지 않고 현재 진행 봉을 제외한다. EMA20에서 2ATR 넘게 이탈한 급락은 추격하지 않는다.
크라켄 chart 거래대금은 종가×거래수량 근사치이며 별도 표시한다.

모든 신규 방향성 숏의 최대 동시 건수는 2건, 건별 비용 포함 예상 위험은 최초원금의
0.3% 이내다. 같은 자산의 중복·당일 재진입 및 계좌 간 담보 합산을 금지한다.
당일 기준자산 미확인, 평가 불가, 당일 실현 또는 총자산 손실 2% 도달 시 신규 숏을 보류한다.
매수/매도 신호 뒤 다음 관측 호가·수량 단계·최소 주문·담보를 다시 검증한다.

숏 담보는 명목금액 120%를 선배치한다. 새 모델은 1.5R 유리해진 뒤 0.5R로 되돌아오면
보호 청산한다. 진입 전 비용·음수 펀딩을 선별하고 실제 펀딩은 기존 거래소별 정산 원장으로
중복 없이 반영한다. 슬리피지·갭 때문에 손절 가격이나 손실 상한이 보장되는 구조는 아니다.

새 판단/진입 보류 원인은 `short_assessments`에 최근 3일을 남기고 텔레그램 데이터 점검 및
모델별 실현손익·승률에 노출한다. 동일 300만원 계좌를 공유하므로 모델별 실현손익을
별도 독립계좌 수익률/MDD로 해석하지 않는다.
