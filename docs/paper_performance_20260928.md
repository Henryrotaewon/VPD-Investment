# 전략검증: 세 모의매매 성과 통합

## 화면

- `전략검증` (`/strategies`): VPD, FAST, 지표가속의 누적 승률 / 누적 수익률을 나란히 표시한다.
- 각 전략 결과 버튼: 첫 줄은 `• 누적 승률 ... / 수익률 ...`, 이어서 일별 승률 / 수익률을 최근 날짜부터 7일씩 표시한다.
- 기존 전략 설명과 연구 메뉴는 `전략 설명·검증 기준`에서 유지한다.
- 세 원장 조회는 로컬 파일/SQLite 읽기 전용이다. 시세 API, 스캔, 주문, 원장 초기화는 호출하지 않는다.

## 공통 계산

- 승률: 순손익이 양수인 **전량 청산 포지션 수 / 전체 전량 청산 포지션 수**. 본전은 분모에 포함한다. 보유·미체결은 제외한다.
- 분할 청산은 모든 체결의 비용 차감 손익을 합산하고 마지막 청산 시각에 한 건으로 집계한다. 수동 전량교체·정리도 실제 모의청산이므로 포함한다.
- 누적 수익률: `(현금 + 보유분 순평가액) / 최초원금 - 1`. 매매별 수익률의 단순 평균·합산이 아니다.
- 일자는 09:00 KST~다음 날 09:00 KST. 일 수익률은 당일 마지막 유효 평가 / 전일 마지막 유효 평가 - 1. 완료일의 평가와 전일 기준값은 해당 경계 직전 10분 안의 유효 기록만 사용한다.
- 새 FAST/지표가속 원장의 시작일은 시작 시각의 최초원금을 기준으로 부분일 수익률을 계산한다. 시작 전 구간의 성과를 만들지 않는다.
- 청산 0건은 승률 `— (청산 0건)`, 가격/일별 평가 누락은 수익률 `— (평가 자료 부족)`로 표시한다. 빈 날을 건너뛰어 며칠치 수익을 하루 수익으로 표시하지 않는다.
- 현재 시세가 오래되면 누적 평가는 `최근 관측`으로 표시하며 일별 수익률 계산에는 유효한 평가만 사용한다. 개별 원장의 비용 가정을 그대로 사용한다.
- 전략별 시작일과 정책 변경 이력이 다르므로 같은 기간·같은 정책의 비교 실험 결과로 해석하지 않는다.

## 원천 자료와 저장

| 전략 | 청산/승패 자료 | 총자산 평가 |
|---|---|---|
| VPD | `paper_events.jsonl` SELL + `paper_state.json`의 CLOSED/closed_positions | 신규 `paper_performance.sqlite3` daily 테이블 |
| FAST | `fast-observe/paper-v1.sqlite3` fills를 BUY~최종 SELL로 연결 | 기존 daily + state의 호가 기반 순평가 |
| 지표가속 | 현행 `indicator_paper/<COHORT>/ledger.sqlite3` SELL 이벤트 | 기존 marks + state의 가격·현금 |

VPD는 기존 모니터(기본 60초), 보고, 리밸런싱·리필 후 보고에서 이미 받은 시세로 일별 마지막 평가를 저장한다. SQLite 파일은 `paper_state.json` 실제 경로 옆, 즉 운영 볼륨에 둔다. 날짜당 한 행만 유지하고 거래 코호트 변경이나 재시작에도 지우지 않는다. 원금·현금·보유 수량/원가 식별값을 함께 저장하여 계정이 바뀐 후 예전 평가를 현재 평가로 재사용하지 않는다. 저장 실패는 매매 작업을 중단하지 않는다.

VPD 전량 청산 식별자는 종목+진입 시각이다. 원장 포지션의 exit_at과 SELL 이벤트 ts는 수십 마이크로초 차이가 있으므로 청산 시각 문자열을 중복제거 키로 쓰지 않는다. 초기 entry_at 없는 이벤트는 종목과 청산 시각(1초 이내)이 일치하는 원장 포지션이 정확히 하나일 때만 연결한다. 포지션 원장의 반올림 전 손익을 우선하며, 합계를 누적 실현손익과 대조한다.

FAST는 부분 청산을 연결한 결과를 원장의 closed/winning 카운터와 대조한다. SQLite는 읽기 트랜잭션으로 state/fills/daily를 일관된 시점에 읽는다. 지표가속은 지연된 이벤트 기록 시각이 아니라 fill_ms로 날짜를 나눈다. 초기화 이전에 삭제된 다른 실험 기록을 섞지 않는다.

기존 VPD 일별 평가 이력은 없으므로 과거 승률만 복원하고 과거 일별 수익률은 생성하지 않는다. 신규 저장을 시작한 뒤 다음 09시 경계부터 일별 비교 기준이 쌓인다. VPD 최초 일일 수익률에 원금을 임의의 소급 기준값으로 쓰지 않는다.
