## 평가에서 얻은 결론
1. 현재 자료만으로 수익성 개선이 입증되지 않음.
2. 진입 지연보다는 원래 신호 기준·비용·보호선 폭과 청산 조건의 설계가 중요한 추가 검증 과제. 서로 다른 거래 집합을 비교해 개선 원인을 단정하면 안 됨.
3. 초기 상장 종목은 과거 10일 동일시간 데이터가 부족하여 기회를 놓칠 수 있음. 별도 신호 유형으로 전향 검증 필요.
4. 미래 검증 시 수수료/슬리피지와 누락표본 및 시장국면을 함께 보존하되, 원시 체결 틱 전체를 장기 저장할 필요는 없음.
