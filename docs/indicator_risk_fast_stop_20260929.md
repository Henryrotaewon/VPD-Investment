# 지표가속 독립 손절 / FAST 중지 — 2026-09-29

사용자 요청: 지표가속 최대 손실 한도를 기존 보유에도 적용하고, 이어서 FAST 포착과 매매를 중지한다.

## 지표가속 PAPER

- 비용 포함 순수익률 −6% 이하에서 전량 매도 신호. 매수원금에는 매수 수수료와 슬리피지가 포함돼 있으며, 매도 수수료·슬리피지도 각각 0.05% 반영한다.
- 손절 기준가격 = 비용 포함 본전 가격 × 0.94. 표시된 수량을 반올림하지 않고 원장의 실제 수량으로 계산한다.
- 별도 worker/HTTP session에서 보유종목 시세만 10초 주기로 조회한다. 전 종목 시간봉 스캔이나 ATR 자료 부족으로 감시가 대기하지 않는다.
- 시세는 관측 시점에서 60초 이내이며 미래 시각이 아니고 해당 매수 이후여야 한다. 오래된 저장 시세로 청산을 만들지 않는다. 요청 중 매도·재매수된 포지션에는 오래된 응답을 적용하지 않는다.
- 기존 보유와 신규 보유 모두 적용. 원금·누적손익·거래 이력·기존 본전/ATR 보호선은 보존한다. 적용 시각과 최초 손절 판단 근거를 원장에 기록한다.
- 감지 시점 뒤 다음 5분 경계부터 실제 존재하는 5분봉 시가에 모의체결한다. 손실 −6% 체결을 보장하지 않으며 이미 −6%를 넘은 종목도 과거 손절가로 소급 체결하지 않는다.
- 기존 매도 대기의 사유와 체결 가능 시각은 보존하고 원장 lock에서 중복 청산을 막는다. 독립 손절 및 기존 매도 주문은 시간봉 스캔과 별도로 체결도 확인한다. 신규매수 정지 중에도 잔여 보유 보호는 유지한다.
- 현재 보호선(시간봉)과 독립 손절선(최신 시세)을 보유화면에 구분한다. 매매이력에 독립 손절 사유를 표시한다.

## FAST 중지

- 운영 supervisor에 `--disable-fast` 적용. Observer에도 중지 상태를 영속 저장한다.
- FAST 신규 포착·신호 재시도·early/control 비교실험 진입을 중지한다. 각 PAPER 원장에 매수 중지 상태를 저장하고 미체결 매수를 취소한다.
- 기존 보유·체결·성과 이력은 보존한다. 기존 보호청산과 재시작/시세단절 청산 규칙은 유지한다.
- FAST와 더블볼린저·CCI는 시세 수신기를 공유하므로 공용 수신기는 유지한다. 더블볼린저 신호/매매를 중지시키지 않는다. FAST 전용 과거자료 보완은 중지한다.
- 조회화면에는 중지 상태를 표시한다. 과거 포착과 매매이력은 계속 조회할 수 있다.

실주문 기능 변경 없음. 모든 변경은 PAPER 경로에 한정한다.
