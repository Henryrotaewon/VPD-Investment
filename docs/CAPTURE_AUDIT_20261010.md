# 급등 포착 점검과 FAST 체결 진단

사용자 승인 범위: BFC FAST 체결/보호선 진단, 매일 급등 종목의 전략별 포착·미매수 사유 자동 점검.

- 매일 09:10 KST 이후 독립 백그라운드 스레드에서 직전 완료 업비트 거래일(09:00~다음 날 09:00)을 점검한다. 재시작 시 가장 최근 완료 기간 1건을 보완하고, 과거 전체 기간은 재실행하지 않는다.
- 현재 상장 KRW 시장의 **직전 종가 대비 장중 고가 +10% 이상** 중 상위 5개를 고른다. 종가 상승률도 함께 보고한다. 상장 폐지 종목, 최초 일봉 및 거래 없는 날은 범위에서 빠질 수 있으며 API 누락 수를 표시한다. 이 사후 표본은 매매전략 백테스트나 승률 검증이 아니다.
- 최초 10% 도달은 실제 5분봉 구간이다. 같은 봉 내부의 매수/도달 순서는 추정하지 않는다. 일봉 100개 미만 제외는 해당 거래일 시작 전에 존재했던 캔들 수로 재구성한다.
- 상승률 분모는 실제 전일 완료 일봉의 종가로 검증한다. 상장 첫날 API가 제공하는 기준가격을 전일 종가로 간주하지 않는다. v2부터 검증된 전일 일봉이 없는 시장은 순위에서 제외하고 누락 수에 포함한다. 보고서 버전 변경 시 캐시를 재산출하며 같은 거래일의 자동 전송 claim은 유지한다.
- VPD, FAST base, 지표가속, 더블볼린저, FAST-BEAR, FAST-DERIVATIVES를 구분한다. 원장 매수, 실제 포착, 당시 중지/취소, 데이터 기준 제외, 확인 불가를 별도 표시한다. 현선물 모델의 고정 대상 밖 종목은 대상 외다.
- FAST 진단은 각 BUY부터 다음 BUY 직전의 부분 SELL을 결합한다. 비용 포함 순손익, 실제 체결 지연, 초기 보호선, 기록된 최고/최저 순평가 및 청산 1·3·5분 후 호가 가정 평가를 제공한다. 가정 평가는 실제 수익으로 표시하지 않는다.
- 텔레그램 `모의투자현황 → 투자전략세부`에서 `급등 포착 점검`, `FAST 매매 진단`으로 들어간다. 기존 최상위/하단 키보드는 유지한다.
- 모든 매매 원장은 SQLite mode=ro/query_only로 읽으며 엔진을 생성하지 않는다. 진단 복사본만 `/data/magi2/capture-audit/`에 기록한다. 매수/매도 조건, PAPER 원금·성과·원장, VPD 리밸런싱은 변경하지 않는다.
- 과거 상세 평가가 보존되지 않은 경우 미포착/조건 실패를 추정하지 않는다. 기존 FAST 5분 평가 및 볼린저/BEAR 최신 평가를 매분 복사하며 압축하여 최근 3일을 보관한다. 도입 직전 기간의 사유 보존 범위는 부분적이다. 원천 데이터에 없는 취소/중지 이유는 확인 불가다.
- 공개 시세 호출은 전용 세션에서 최대 초당 2회, 타임아웃/429 재시도를 제한한다. 일별 결과는 별도 JSON으로 보관한다. 텔레그램 전송 전에 일자별 영속 claim을 기록한다. 전송 결과가 불확실하면 자동 재발송하지 않으며 저장된 보고서는 메뉴에서 조회한다.
- 새 기능은 계정 비밀값을 조회/로그하지 않는다. 운영 로그 `fast_trade_audit`는 PAPER 체결 및 진단 증거만, `capture_audit_daily`는 해당 일별 점검 증거만 포함한다.

검증: 부분청산·재진입 분리, 원장 읽기 전용, 일자/09:10 경계, 진행 중 일봉 제외, 데이터 누락, 기록된 중지, 증거 중복·보관기간, 전송 불확실 상태의 재시작 중복 방지, 텔레그램 콜백 권한 확인.
