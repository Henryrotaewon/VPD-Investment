# VPD 리필 오류 수정 — 2026-09-26

## 확인된 원인

17:30:55 KST Telegram 리필 요청 후 17:30:59에 `Today's VPD snapshot is unavailable. Refill aborted.` 오류가 발생했다. 리필 전용 경로가 GitHub의 `data/vpd_latest.json`을 당일 자료로 요구했으나 파일의 기준시각은 9월 25일 23:54였다. 로컬에는 9월 26일 17:23 기준 시점 스캔이 있었지만 해당 경로가 이를 사용하지 않았다. 당일 자료 검사에서 먼저 예외가 발생하므로 후속 Fresh Scan에도 도달하지 못했다.

## 수정

- 리필을 리밸런싱과 같은 현재 시점 스캐너에 연결한다. 요청 직전 완료 분봉을 기준으로 새 전종목 VPD를 생성한다.
- 스캔은 별도 작업자로 수행하며 기존 보호 모니터는 계속한다. 스캔이 끝나면 직전 원장을 다시 읽고 동일 기준시각의 스냅샷으로 리필한다.
- 후보 TOP10과 차순위는 같은 로컬 스냅샷에서 조회한다. GitHub JSON/CSV 및 토큰을 리필 선행조건에서 제거한다.
- 기존 리필 기준(VPD 75점 이상, 당일 TP/SL 청산 종목 제외, 보유 수·당일 균등금액·현금 한도)을 유지한다. 기존 보유 종목을 리필 때문에 매도하지 않는다.
- 자료 검증 실패·시세 조회 중 만료는 매수 전에 중단한다. 후보 없음·현금 부족·보유한도 도달·시세 부족은 이유를 표시하고 정상적으로 현금을 유지한다.
- CLI의 두 진입 경로도 같은 리필 구현을 사용한다.
- 기존 일회성 PAPER 요청에 `mode=refill`을 지원한다. 기본 `morning` 호환, 요청 ID 선점·만료·재시작 재실행 방지를 유지하고 허용되지 않은 실행 모드는 거부한다.

검증은 오래된 GitHub 자료 비의존, 요청 시각 일치, 만료 시 미체결, 반복 요청 중복 매수 방지, VPD 점수/재진입 기준 유지, 모니터와 스캔 동시 수행 및 매매 직렬화, 일회성 요청 재실행 방지를 포함한다.
