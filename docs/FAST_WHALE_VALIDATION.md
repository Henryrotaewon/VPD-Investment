# FAST · WAVE 전진 검증 기준 — WHALE은 WAVE 기초자료

현재 판정은 **미검증**이다. 신호 생성 코드와 테스트 통과는 투자성과 검증이 아니다. 아래 기준은 이번 검증을 위한 사전 계획이며, 이미 달성한 실적이 아니다.

## 관측과 예측의 분리

- FAST: 각 거래소 내부의 빠른 상승 종목 포착 전략. 새 `fast-rise-v1` 후보는 MICRO 약 10초 수익률 +20bps(0.20%) 이상과 직전 구간 대비 거래량 2배 이상을 모두 요구한다. 최소 8초 관측·연속 특징 3개·동일 거래소/종목 10초 쿨다운을 적용한다. 하락 둔화·음수 수익률·SELL은 제외한다. 이 수치는 초기 연구 기본값이며 검증된 최적 임계치가 아니다. 현재 후보 범위는 WAVE 공통 선별 5종목으로 제한되며 거래소 전체 종목 탐색기는 아직 미구현이다. 기존 `derived-v2` 가속 이벤트는 보존하지만 새로운 FAST 표본에 섞지 않는다.
- WAVE: 글로벌 거래소의 움직임 시작·확산·국내 전파를 검토하는 전략.
- WHALE: WAVE 검토에 사용하는 여러 기초 데이터 중 하나이며 독립 투자전략이 아니다. 공개 BTC 대규모 전송 관측. 총 전송량에는 거스름돈/내부이동이 포함될 수 있다. 주소 라벨의 출처·알려진 시점·충돌 여부를 보존한다. 소유권이나 입출금 방향을 입증하지 못하면 UNKNOWN으로 남긴다.
- UNKNOWN WHALE 자료의 첫 검토 대상은 이후 변동성·거래량 변화와 거래소 반응의 연관성이다. 상승 예측이나 코인별 매수 신호로 치환하지 않는다. 방향 가설이 필요하면 학습구간에서 별도로 정의하고 고정한다.
- WAVE 선행성은 로컬 수신시각·피드 지연 해상도보다 작은 시간차를 의미 있는 선행으로 해석하지 않는다.

## 평가 단위와 비용

신호가 관측되어 실제로 사용 가능해진 시각 이후 10/30/60/300초를 보조 지평으로 사용한다. 주평가 지평은 사전에 60초로 고정하며 최상의 지평을 사후 선택하지 않는다. 추가 지평으로 선택하면 별도 미사용 구간에서 재검증한다.

FAST는 발생 거래소에서 평가하며 타 거래소 전파는 별도 가설이다. 동일 종목·거래소·방향의 중첩 300초 이벤트는 하나의 클러스터로 다루고, 독립 거래처럼 수를 늘리지 않는다.

현물 매수의 기본 가격은 진입 ask, 청산 bid다. 진입/청산 수수료율을 f_in, f_out이라고 하면:

`net_return = exit_bid * (1-f_out) / (entry_ask * (1+f_in)) - 1`

호가 깊이를 확보하면 사전 고정 주문금액으로 체결가능 수량을 적분하여 VWAP를 계산한다. 실제 적용 수수료와 시장 충격을 확인하지 못한 결과는 '가정 비용 시나리오'로 표시한다. 최우선호가 수익률을 실체결 수익으로 표기하지 않는다. SELL은 현물 보유분의 청산/회피 효과로 따로 검증하며 가상 공매도 수익을 현물 전략 수익에 합산하지 않는다.

## 누락과 비교군

- 미래 호가가 없는 건, 피드 공백, 재시작을 통한 관측 단절을 각각 표시한다. 제외율을 분모와 함께 제시하며 누락을 손실이나 비반응으로 대체하지 않는다.
- 비신호 비교군은 같은 거래소·종목·시간대·변동성/유동성 구간에서 선정하되 모두 신호 시점 이전 정보로 매칭한다.
- VPD 단독, FAST 단독, VPD+FAST, WAVE 결합, WAVE에 WHALE 맥락 추가를 분리해 증분 효과를 비교한다. 서로 겹치는 전략의 손익을 단순 합산하지 않는다.
- 날짜 순으로 학습/검증/최종 미사용 구간을 나누고 최대 관측 지평 이상의 간격을 둔다. 점수 임계치·보유시간·비용 가정은 학습구간에서만 선택한다.

## 보고 및 승격 판단

거래소·전략·방향·시장상태별로 원표본/독립 클러스터 수, 데이터 제외율, 평균·중앙 순수익, 순수익 양수 비율, 최대 유리/불리 변화, 손익의 날짜·종목 편중을 보고한다. 일자 또는 이벤트 클러스터를 단위로 부트스트랩하여 평균 순수익 및 비교군 대비 증분의 95% 신뢰구간을 산출한다. 중첩 건을 독립 시행으로 간주한 좁은 신뢰구간을 사용하지 않는다.

초기 운영 목표는 최소 14일 및 200개 독립 클러스터의 관측이다. 이는 분석을 시작하기 위한 목표이며 통계적 충분성을 보장하지 않는다. 유효 표본이 부족하거나 시장 상태가 한쪽으로 쏠리면 기간을 연장한다. 사전에 고정한 미사용 구간에서 비용 차감 순수익과 비교군 대비 증분의 신뢰구간 하한이 모두 0을 웃돌고, 별도 후속 전진 구간에서 재현되어야 Shadow 주문 후보로 승격한다. 여러 조합을 탐색하면 다중 비교를 보정하거나 최종 미사용 구간에서 한 번만 확인한다.

현재 신호별 비용·체결·실현손익이 연결된 전진 평가기는 미완료다. 따라서 이 문서의 수익률·신뢰구간을 이미 측정했다고 보고하면 안 된다. 기존 WAVE `quote-v2` 평가 또한 수수료 및 깊이 슬리피지를 포함하지 않으므로 이 기준 통과를 대신할 수 없다.

## Telegram view

`/fast`: FAST 후보의 거래소·종목·구간 상승률·거래량 배수·관측 길이·KST 발생 시각. `/wave`: 글로벌 WAVE 검토용 WHALE 온체인 참고자료이며 전체 WAVE 전파 보고서는 아님. `/signals`: 두 역할을 구분한 요약. WHALE 전송 규모점수를 독립 전략 점수로 표시하지 않는다.
